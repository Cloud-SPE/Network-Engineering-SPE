# Decision Index

No Cloud SPE decision record has been accepted in this repository yet.

Create a decision record when a choice changes Cloud SPE scope, ownership,
funding, acceptance evidence, or a cross-repository contract. Name files
`YYYY-MM-DD-short-title.md` and include status, deciders, context, decision,
alternatives, consequences, and links to affected Beads issues and documents.

Wider Network Engineering SPE decisions should be linked from their own source
of truth. Record only their consequences for Cloud SPE work. The most urgent
unresolved Cloud SPE choices identified in the current references are tracked in
Beads rather than duplicated as an open-task list here.
