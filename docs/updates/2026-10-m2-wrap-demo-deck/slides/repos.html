Two GitHub organizations hold the code. NE-Build-Track is ours: builder core, John's enterprise desk and ChatLPT, plus forks of the three upstream projects we depend on (the node remote signer, Clearinghouse Batteries and the Python SDK), each tagged build-track/v0.1.0 at the exact revision we tested so any build can be reproduced. The livepeer organization is upstream: fixes we need go there first, and our forks follow. The milestones and tickets are on the project board linked at the bottom.
