M2 → M3

M2 built the engine for all seven. M3 proves them in one funded journey.

The build track's accepted baseline defines seven outcomes: what any builder must be able to do without becoming a Livepeer expert. Get one credential, with payment keys kept out of their hands. Discover what the network offers. Understand the rate before running anything. Invoke a capability, over REST or inside their own app. Get a result, or a failure they can understand. Pay without holding crypto: an operator funds the network side and each user spends from an allocation. And see their usage and what it was charged. M2 built and tested the engine pieces behind each one; M3's gate is a single funded journey that shows all seven end to end. Retail prices, customer accounts and invoices stay in the enterprise's own app.
