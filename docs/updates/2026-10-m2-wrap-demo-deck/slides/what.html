What M2 built

One engine any app can build on

Builder core lets an app run paid AI jobs on Livepeer, and know what every job cost.

Who can run what

Keys and policies decide who runs jobs and whose allocation pays

Run and pay

Finds a runner, pays it, and records every attempt

What it cost

Matches each network charge to the job that caused it

Use it two ways: import the Python package, or run it as a REST service.

Builder core is a shared engine, not an app. An enterprise app keeps its own users and prices; builder core handles the Livepeer side: who is allowed to run jobs and spend which allocation, finding a runner and paying it, and attributing every network charge to the job that caused it, including jobs that failed after paying. It ships as one Python package you can import, or run as a REST service. The two demos at the end use it each way.
