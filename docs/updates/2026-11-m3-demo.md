## Demo run sheet

On the local console stack: the console on 127.0.0.1:3060, the engine on 127.0.0.1:8090,
[NE-Build-Track/builder-core-console](https://github.com/NE-Build-Track/builder-core-console).

**Operator, signed in with the admin key:**

1. Health: the one verdict, then each component's checks. Delivery errors now warn only for errors
   in the last hour (console D22).
2. Money: the grant and its allocations, with days of balance left.
3. Operator: provision a new actor from the grant and fund its allocation. Review the request
   before sending it, then show the REST request and response and copy it as `curl`.
4. Issue the actor's key; it is shown once, then only its prefix.

**Builder, signed in with that key:**

5. The catalog: each offering with its rate, the rate's source and its age.
6. Run a streamed Qwen chat and watch it arrive, then a FLUX schnell image.
7. Open the job: its attempts, its result, and its cost moving from pending to delivered.
8. Usage and allowance: what the actor has spent, matching Batteries.

Optional: open 127.0.0.1:8090/docs to show the same calls in the engine's Swagger UI. A chat costs
about $0.0001 and an image about $0.003. This is not the ISS-25 gate run; say so during the demo.
